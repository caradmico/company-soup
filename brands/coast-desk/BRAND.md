## Positioning
Coastal newsroom for Cara’s bylines. Ink on newsprint. Hed wall energy — not a watershed brochure, not a web studio.

## Color
| Token | Hex | Use |
|-------|-----|-----|
| `--ink` | `#121212` | Body text, rules |
| `--paper` | `#f3efe6` | Page (warm newsprint, cooler than Demeter cream) |
| `--rule` | `#1a1a1a` | Hairlines, masthead bar |
| `--spot` | `#b33a2b` | Hed kicker / pull-quote mark (press red — not GO teal, not Demeter gold) |
| `--mute` | `#5c5650` | Decks, dates |
| `--card` | `#fffcf7` | Quote cards |

## Type
- **Display / masthead:** `"Libre Baskerville", Georgia, serif` — newspaper nameplate
- **Body:** `"Source Serif 4", Georgia, serif`
- **UI / dates / outlet tags:** `"IBM Plex Mono", ui-monospace, monospace`
- Sizes: masthead ~1.75–2.25rem; body 1.05rem / 1.55; mono labels 0.75rem uppercase tracked

## Voice
Short hed. Outlet + date. Pull-quotes earn the wall. No “capability plates.” No invent-speak. No “The sell is.”

## Logo mark
Wordmark only: **COAST DESK** in Libre Baskerville small-caps / tracked, with a 2px black rule under. Optional thin red spot rule (2px × 2.5rem) left of the active section. No GO teal mark. No fir glyph.
